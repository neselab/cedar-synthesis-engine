Grade Entry and Release Access

A user with the instructor of record or teaching assistant role may enter a grade only when the grade entry is in draft status, the current request time is strictly earlier than the grading deadline supplied with the request, and the learner named on the grade entry is on its module’s roster.

A user with the instructor of record role may release a grade only when that user is the grade entry’s posting author, the entry is in posted status, and the current request time is at or after the scheduled release start and strictly before the scheduled release end supplied with the request. All times are UTC.

These are the only permissions: each activity is permitted if and only if all its stated requirements hold, based on the current recorded facts. These permissions neither change record states nor require an order between the activities.
