Shipment Delivery Confirmation

A user may confirm delivery of a shipment only if they hold the driver or depot supervisor role, the shipment’s piece count is at least 0, and the request is made on the depot network. The user must be the shipment’s driver of record unless an expedite has been declared and the user holds the depot supervisor role. This exception waives only the driver-of-record requirement; all other requirements still apply.

If the shipment’s hazmat class includes “toxic,” a custody signature must have been captured. If the shipment’s piece count exceeds 100, the host application must confirm that the additional review is complete.

These are the only permissions: delivery confirmation is allowed only when all applicable requirements above are met, and no other actions are permitted.
