Lease Execution Access

A user may execute an executed lease record only if they hold the broker or compliance officer role, the lease’s monthly rent is at least $0.00, the lease’s segment includes “regulated,” and the request is made on the brokerage network. If monthly rent exceeds $10,000.00, the user must hold the compliance officer role. Amounts in the supplied records are stored in whole US cents.

The user must also be the lease’s recorded reviewer, unless a court order has been declared and the user holds the compliance officer role. This exception waives only the reviewer requirement; all other requirements still apply.

These are the only permissions granted: lease execution is permitted only under these conditions, and no other actions are permitted.
