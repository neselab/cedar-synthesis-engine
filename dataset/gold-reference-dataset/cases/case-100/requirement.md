Reimbursement Disbursement

A user may disburse a reimbursement only if the user holds the controller role, the reimbursement amount is at least $0.00, and the associated expense report has a recorded approver. If no approver is recorded, disbursement is not permitted.

When the reimbursement amount exceeds $250.00, the user disbursing it must also be different from the report’s approver. This separation requirement does not apply to amounts of $250.00 or less; all other requirements still apply. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: disbursement is permitted when all applicable requirements above are met, and no other activity is authorized by this requirement.
