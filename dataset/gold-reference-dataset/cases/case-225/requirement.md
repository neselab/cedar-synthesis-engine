Order Refund Authorization

A user may issue a refund only if they hold the service rep or manager role, have used multi-factor authentication, and the related order has shipped status. The refund amount, order item total, and order tax amount must each be at least $0.00, and the order’s loyalty tier must be 0, 1, or 2. Amounts in the supplied records are stored in whole US cents.

If the order’s item total plus tax exceeds $2,000.00, or the refund amount exceeds $1,000.00, the user issuing the refund must not be the user who placed the order. This restriction does not apply when both amounts are at or below their respective thresholds; all other requirements still apply.

These are the only permissions: a user may issue a refund if and only if all applicable requirements above are met, and no other activity is authorized.
