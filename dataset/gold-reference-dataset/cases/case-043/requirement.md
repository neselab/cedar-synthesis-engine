Document Viewing Access

A user may view a document only if the user has the attorney role and is the document’s author. Holding the paralegal or records manager role without also holding the attorney role is not sufficient. The document must either have a status other than sealed or be marked as filed.

The request’s current date and time must be at or after its scheduled start and strictly before its scheduled end, using UTC. If the document is marked privileged, privileged access must also be authorized for the request; this additional requirement does not apply to documents not marked privileged.

These are the only permissions: document viewing is allowed only when all applicable requirements above are met, and no other actions are permitted.
