Payroll Run Approval

A user may approve a payroll run only if the user holds the manager role, the request uses the VPN, and the payroll run’s amount is at least $0.00. Holding the payroll administrator role without also holding the manager role is not sufficient.

If the payroll run’s amount exceeds $100,000.00, the approving user must differ from the run’s preparer. This separation requirement does not apply at or below $100,000.00; all other requirements still apply. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: approval is permitted when all applicable requirements above are met, and no other actions are permitted.
