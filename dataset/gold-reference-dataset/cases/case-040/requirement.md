Archived Document Viewing

A user may view a document only if the user holds at least one of the author, editor, viewer, or compliance officer roles and owns the document. The user’s clearance and the document’s classification must each be one of 0, 1, 2, or 3, and the user’s clearance must be at least the document’s classification.

The document must have archived status and carry the “review_required” label, and the request must be made on the corporate network. These are the only permissions: viewing is allowed when all these requirements are met, and no other actions are permitted under this requirement.
