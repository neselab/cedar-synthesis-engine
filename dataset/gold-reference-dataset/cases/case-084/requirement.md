Escrow Approval and Disbursement Authorization

A user may approve an escrow file as clear to close only if the user is a Title Officer or Escrow Manager, is not the file’s escrow officer, and dual control has been verified. The file must have a held amount of at least $0.00, a nonnegative payee count, and a file code beginning with “SETTLEMENT-”; any suffix, including an empty suffix, is permitted.

A user may authorize a disbursement only if the user is a Senior Escrow Officer or Escrow Manager and has an authority level of 0, 1, 2, or 3. The disbursement amount and its escrow file’s held amount must each be at least $0.00. The escrow file must have a disbursement tier of 0, 1, 2, or 3 and a status of cleared to close, and dual control must have been verified. If the disbursement amount exceeds $50,000.00, the user must also be an Escrow Manager; this additional role requirement does not apply at exactly $50,000.00.

Amounts in the supplied records are stored in whole US cents. These are the only permissions, and each activity is permitted if and only if all its stated requirements are met using current recorded facts. These permissions neither change records nor require an execution order between the activities.
