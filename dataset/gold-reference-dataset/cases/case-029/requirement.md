Viewing Applicant Records

A user may view an applicant record only if the user holds the supervisory officer role, is the record’s assigned officer, and accesses it on the government network. The record must have active status. Both the user’s clearance and the record’s data sensitivity must be 0, 1, or 2, and the user’s clearance must be at least the record’s data sensitivity. Holding other roles does not remove these requirements.

These are the only permissions granted; no other actions are permitted under this requirement.
