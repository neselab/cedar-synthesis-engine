Course Module Viewing Access

A user may view a course module if they hold the coordinator role, are on the module’s roster, and request access from the institution network, provided the module is not locked and the level requirements below are met. Other roles do not substitute for the coordinator role.

The user’s completed level and the module’s prerequisite level must each be 0, 1, or 2, and the user’s completed level must be at least the module’s prerequisite level.

These are the only permissions granted by this requirement.
