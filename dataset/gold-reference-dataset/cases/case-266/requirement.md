Inpatient Prescription Access

A user may countersign a prescription only if the user holds the attending physician role and is the prescription’s recorded prescriber.

A user may dispense a prescription only if the user holds the pharmacist role, the prescription has countersigned status, and the user has used multi-factor authentication for the request.

A user may write a prescription only if the user holds the attending physician role, is not the prescription’s patient, the prescription has draft status, and the user has used multi-factor authentication for the request.

These are the only permissions: each activity is permitted when and only when all its stated requirements are met. These permissions do not change record states or require an order of activities.
