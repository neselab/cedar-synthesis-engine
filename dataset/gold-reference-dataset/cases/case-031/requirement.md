Viewing Job Applications

A user may view a job application if and only if the user holds the recruiter role, belongs to the application's hiring team, and makes the request on the corporate network, and the application's status is interviewing. Holding the hiring manager, interviewer, or coordinator role without the recruiter role does not qualify the user for access.

The user's personal-information clearance and the application's personal-information sensitivity must each be 0, 1, or 2, and the user's clearance must be at least the application's sensitivity. These are the only permissions granted.
