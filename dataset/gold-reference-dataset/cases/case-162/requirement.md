Viewing Inpatient Medical Records

A user may view an inpatient medical record only if the user holds the Attending Physician or resident role, the record is finalized, and the user has used multi-factor authentication. A nurse role alone is insufficient; users may hold multiple roles. The user’s clearance level and the record’s sensitivity level must each be 0, 1, or 2.

The user’s clearance level must be at least the record’s sensitivity level unless an emergency has been declared. A declared emergency waives only this clearance comparison; all other requirements still apply. These are the only permissions: viewing is allowed when all applicable requirements above are met, and no other actions are permitted.
