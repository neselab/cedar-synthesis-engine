Payroll Run Approval

A user may approve a payroll run only if the user has the manager role and the run’s amount is at least $0.00. Holding the payroll administrator role without the manager role is not sufficient. If the amount exceeds $25,000.00, the approving user must differ from the run’s preparer; this separation requirement does not apply at exactly $25,000.00 or below. Amounts in the supplied records are stored in whole US cents.

The request’s current time must be at or after its scheduled approval start time and strictly before its scheduled approval end time. All times are UTC.

These are the only permissions: approval is allowed when all applicable requirements above are met, and no other actions are permitted.
