Datacenter Cage Entry

A user may enter a datacenter cage only if they hold at least one of the facility tech, tenant engineer, or escort roles. Both the user's clearance level and the cage's zone clearance must each be 0, 1, or 2. The user's group must be the same as, or descend from, the cage's site zone.

The cage must be active unless the request is during a maintenance window, the user holds the facility tech role, and the cage is locked. This exception waives only the active-status requirement; all other requirements still apply. The user's badge must identify that user as its holder, and the request's current time must be strictly earlier than the badge's expiration time. Times are in UTC.

These are the only permissions: cage entry is allowed exactly when all applicable requirements above are met, and no other actions are permitted.
