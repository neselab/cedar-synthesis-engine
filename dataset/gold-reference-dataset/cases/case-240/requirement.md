Complimentary Benefit Authorization

A user may authorize a complimentary benefit only if they hold the Shift Manager or Front Office Manager role, the request indicates that the manager is on duty, and the authorization’s perks include a suite upgrade. The authorization must have a comp value of at least $0.00 and an item count of at least zero. Amounts in the supplied records are stored in whole US cents.

If the item count exceeds 10, the authorizing user must be different from the authorization’s requester. If the comp value exceeds $100.00, the authorizing user must hold the Front Office Manager role; this additional role requirement does not apply at exactly $100.00.

These are the only permissions: authorization is permitted only when all applicable requirements above are met, and no other activities are permitted under this requirement.
