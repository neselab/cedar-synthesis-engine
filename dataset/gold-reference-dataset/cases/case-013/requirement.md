Grant Award Approval and Fund Obligation

A user may approve an award only if the user has the program officer role, has approval authority of 0, 1, or 2, and is not the applicant for the award’s application. The award must be pending, its amount must be at least $0.00, and its application’s funding tier must be 0, 1, or 2. Holding the grants officer role alone does not permit approval.

A user may obligate funds for an award only if the user has the grants officer role, is not the award’s recorded approver, and makes the request on the government network. The award’s amount must be at least $0.00. If the award is flagged as high risk, the high-risk review must also be completed; this review requirement applies only when that flag is true.

Amounts in the supplied records are stored in whole US cents. These are the only permissions: each activity is permitted only when all its stated requirements are met. These permissions neither change recorded facts nor require an execution order between approval and obligation.
