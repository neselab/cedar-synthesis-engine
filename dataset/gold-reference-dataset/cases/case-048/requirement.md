Order Refund Authorization

A user may issue a refund only if they hold the service rep or manager role, have used multi-factor authentication, and the request is in the cardholder zone. The refund amount and the order’s item total and tax amount must each be at least $0.00, and the order’s loyalty tier must be either 1 or 2. Amounts in the supplied records are stored in whole US cents.

If the order’s item total plus tax exceeds $500.00, the user issuing the refund must not be the user who placed the order. This restriction does not apply when that total is exactly $500.00 or less; all other requirements still apply.

These are the only permissions: issuing a refund is permitted if and only if all applicable requirements above are met, and no other activity is authorized by this requirement.
