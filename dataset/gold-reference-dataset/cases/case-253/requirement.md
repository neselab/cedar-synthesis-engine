Asset Calibration Access

A user may calibrate an asset only if the user holds the calibration technician or senior technician role, the user’s certification level and the asset’s equipment class are each 0, 1, 2, or 3, and the asset’s measurement point count is nonnegative. The asset must have due status, and the host application must confirm that the clean room has been certified.

The user’s certification level must be at least the asset’s equipment class unless an emergency has been declared and the user holds either of the required roles. This exception waives only the certification-level comparison; all other requirements still apply. If the asset has more than 10 measurement points, the host application must also confirm completion of the additional review.

These are the only permissions: calibration is permitted only when all applicable requirements above are met, and no other activity is authorized by this requirement.
