Number Port Authorization

A user may authorize a number port only if they hold the porting specialist or porting supervisor role and the port request has validated status, a number block size of at least 0, and account numbers that include "HIGHVALUE-002". The request’s subscriber region must be the same hierarchy node as, or descend from, the user’s assigned group.

The current time supplied by the host must be at or after the scheduled authorization start time and strictly before the scheduled authorization end time. Times are in UTC. If the number block size exceeds 10, the host must also confirm completion of the additional review; this review requirement does not apply to block sizes of 10 or less.

These are the only permissions: authorization is permitted only when all applicable requirements above are met, and no other actions are permitted.
