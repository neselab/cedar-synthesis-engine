Inpatient Prescription Access

A user may countersign a prescription only if the user holds the attending physician role and is the prescription’s recorded prescriber.

A user may dispense a prescription only if the user holds the pharmacist role, the prescription’s status is countersigned, and the user has used multi-factor authentication.

A user may write a prescription only if the user holds the attending physician role, is not the prescription’s patient, and has used multi-factor authentication.

These are the only permissions: each activity is permitted when all its stated requirements are met, based on current recorded facts. Users may hold multiple roles; role membership does not establish that a user is the recorded prescriber or patient. These permissions neither change records nor require an order of activities.
