Escrow Approval and Disbursement Authority

These are the only permissions: a user may perform either activity below if and only if all requirements for that activity are met. Amounts in the supplied records are stored in whole US cents. These permissions neither change records nor require either activity to precede the other.

Clear-to-close approval

A user may approve an escrow file as clear to close only if the user holds the title officer or escrow manager role, is not the file’s escrow officer, and the file has a held amount of at least $0.00 and a payee count of at least 0. If the payee count exceeds 2, the user must hold the escrow manager role. If any file party is among the request’s enhanced due diligence parties, enhanced due diligence must have been completed.

Disbursement authorization

A user may authorize a disbursement only if the user holds the senior escrow officer or escrow manager role and the request is made on the corporate network. The user’s authority level and the associated escrow file’s disbursement tier must each be one of 0, 1, 2, or 3, and the authority level must be at least the tier. The disbursement amount and the associated escrow file’s held amount must each be at least $0.00, and the file’s lien status must not contain tax_lien.
