# Escrow disbursement authorization requirements

Case: case-012
Domain: escrow_disbursement
Selected actions: approveClearToClose, authorizeDisbursement

## Purpose

Determine whether a user may perform each of these operations: approve an escrow file as clear to close; authorize a disbursement.
Each request names one user, one action, one resource, and trusted context supplied by the host application. Decide whether to allow that request using the current recorded facts.
The permissions do not perform state changes or assert an execution order between actions.

## How permissions apply

For each action, allow access if and only if the stated requester and resource types match and ALL requirements in that action section hold. Otherwise deny access. Deny requests for actions not listed here.
Each unless clause waives only the requirement in its own sentence. It never grants access or waives other requirements.
If a condition in an If sentence is false, only that sentence imposes no additional duty; every other requirement still applies.
Users may hold multiple roles. Role membership and ownership are distinct facts. Money is expressed in integer USD cents. Times are UTC. Daily time windows recur every day of the week.
Brackets identify exact fields or entity types. Role and status values identify entities of their declared types. True and false are Boolean values. Every listed interval includes only the endpoints explicitly stated.
Optional-field presence is explicit in the rules. A guarded predicate is false if a field it needs is missing; preserve the enclosing negation, condition, or waiver. Requirements about presence remain binding.
The separately supplied Cedar schema defines entity types, fields, optionality, action types, and valid enum vocabulary. Use that schema unchanged. Its declarations alone add no authorization requirements; declaring schedule fields does not impose a time window.

## Permission to approve an escrow file as clear to close
Action: approveClearToClose
Requester type: User.
Resource type: EscrowFile.

Allow this action if and only if all the following requirements hold:

- Access requires that at least one of [the user has the "TitleOfficer" role; the user has the "EscrowManager" role].
- Access requires that the escrow file's held amount [resource.heldAmount] is at least 0 USD cents.
- Access requires that the escrow file's payee count [resource.payeeCount] is at least 0.
- Access requires that the user [principal] differs from the escrow file's escrow officer [resource.escrowOfficer].
- If the escrow file's parties [resource.parties] has at least one member in common with the request's enhanced due diligence parties [context.enhancedDueDiligenceParties], access requires that the enhanced due diligence has been completed [context.enhancedDueDiligenceCompleted].
- If the escrow file's payee count [resource.payeeCount] exceeds 2, access requires that the user has the "EscrowManager" role.

## Permission to authorize a disbursement
Action: authorizeDisbursement
Requester type: User.
Resource type: Disbursement.

Allow this action if and only if all the following requirements hold:

- Access requires that at least one of [the user has the "SeniorEscrowOfficer" role; the user has the "EscrowManager" role].
- Access requires that the user's authority level [principal.authorityLevel] is one of [0; 1; 2; 3].
- Access requires that the disbursement's amount [resource.amount] is at least 0 USD cents.
- Access requires that the disbursement's escrow file / disbursement tier [resource.escrowFile.disbursementTier] is one of [0; 1; 2; 3].
- Access requires that the disbursement's escrow file / held amount [resource.escrowFile.heldAmount] is at least 0 USD cents.
- Access requires that the user's authority level [principal.authorityLevel] is at least the disbursement's escrow file / disbursement tier [resource.escrowFile.disbursementTier].
- Deny access when the disbursement's escrow file / lien status [resource.escrowFile.lienStatus] contains "tax_lien".
- Access requires that the request is on the corporate network [context.onCorporateNetwork].
