Complimentary Benefit Access

These are the only permissions for users to apply or authorize a complimentary benefit on a comp authorization record, and each permission requires all of its stated conditions. Decisions use current recorded facts; these permissions neither change records nor require an order between the activities. Amounts in the supplied records are stored in whole US cents.

A user may apply a complimentary benefit if they hold the front desk agent or guest services host role. Their comp authority level and the record’s guest tier must each be 0, 1, 2, or 3, and their authority level must be at least the guest tier. The comp value must be at least $0.00, and the record’s loyalty group must be the same hierarchy node as, or a descendant of, the user’s assigned group. If the record’s perks include beverage_credit, the voucher perks supplied with the request must also include beverage_credit.

A user may authorize a complimentary benefit if they hold the shift manager or front office manager role, the comp value is at least $0.00, and the item count is nonnegative. If the item count exceeds 1, the authorizing user must differ from the user who requested the benefit. If the comp value exceeds $500.00, the authorizing user must hold the front office manager role.
