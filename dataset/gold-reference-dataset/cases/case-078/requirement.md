Shipment Dispatch and Delivery Confirmation

A user may confirm delivery of a shipment only if the user holds the driver or depot supervisor role, the shipment has a nonnegative piece count, its recorded status is “intransit,” and proof of delivery is confirmed in the request. If the shipment’s hazmat classes include “flammable,” a custody signature must also have been captured.

A user may dispatch a shipment only if the user holds the driver or dispatch manager role, the shipment has a nonnegative piece count, its recorded status is “created,” and its hazmat classes include “toxic.” If the piece count exceeds 1,000, the user must hold the dispatch manager role.

These are the only permissions: each activity is permitted if and only if all its stated conditions are met, using the current recorded facts. These permissions neither change shipment records nor require an order between the activities.
