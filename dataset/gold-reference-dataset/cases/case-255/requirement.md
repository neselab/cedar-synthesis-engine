Lab Result Release

A user may release a lab result if the user holds the pathologist or ordering provider role, or if emergency release is requested and the user both holds the medical technologist role and is the result’s verifier. The result’s sensitivity must be 0, 1, or 2. For sensitivity 1 or 2, the user must also hold the pathologist role.

The user must not be the result’s verifier unless emergency release is requested and the user holds the medical technologist role and is that verifier. This exception waives only the restriction on releasing a result the user verified; all other requirements still apply. If the result is flagged as critical, the critical release review must have been completed.

These are the only permissions: release is permitted only when all applicable requirements above are met, and no other activities are authorized.
