Number Port Completion

A user may complete a number port on a port request only if the user holds the line technician or porting supervisor role, the request’s number block size is at least zero, its port types include “inter_carrier,” and regulator escalation is marked true in the trusted request context.

The user must also be the request’s assigned technician unless a port freeze override has been declared in the trusted request context and the user holds the porting supervisor role. This exception waives only the assigned-technician requirement; all other requirements still apply.

These are the only permissions granted by this requirement.
