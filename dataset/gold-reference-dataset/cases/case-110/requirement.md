Network Change Approval

A user may approve a network change request only if the user holds the cabapprover role and has an authority level of 0, 1, 2, or 3 that is at least the request’s change risk. The request’s change risk must also be 0, 1, 2, or 3.

The request must be marked as an emergency change, include “transport” among its change categories, and have a change code beginning with “CORE-”, followed by any sequence of characters, including none. Its affected node count and rollback step count must each be nonnegative, and its estimated cost must be at least $0.00. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: approval is permitted when all these requirements are met, and no other actions are authorized.
