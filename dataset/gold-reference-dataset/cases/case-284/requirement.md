Inpatient Prescription Access

A user may countersign a prescription only if they hold the Attending Physician role, are the prescription’s recorded prescriber, and the prescription is in draft status.

A user may dispense a prescription only if they hold the pharmacist role, the prescription is in countersigned status, and they have used multi-factor authentication for the request.

A user may write a prescription only if they hold the Attending Physician role, are not the prescription’s patient, and have used multi-factor authentication for the request.

These are the only permissions: each activity is permitted if and only if all its stated requirements are met using current recorded facts. These permissions neither change records nor require an order of execution.
