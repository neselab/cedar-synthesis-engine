Patent Application Examination

A user may examine a patent application only if the user holds the examiner role, is not the application's inventor, and belongs to the application's team. The application must have underExamination status, the request's current date and time must be strictly earlier than the application's bar date, and the user must have used multi-factor authentication. Dates and times are evaluated in UTC.

These are the only permissions: examination is permitted when all of these requirements are met, and no other activities are authorized by this requirement.
