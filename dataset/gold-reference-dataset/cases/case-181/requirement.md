Escrow Approval and Disbursement Access

These are the only permissions: a user may perform either activity below if and only if all requirements for that activity are met. Amounts in the supplied records are stored in whole US cents. These permissions neither change records nor require the activities to occur in a particular order.

Clear-to-close approval

A user with the title officer or escrow manager role may approve an escrow file as clear to close only when the file has funded status, its held amount is at least $0.00, its payee count is at least zero, and the request is made on the corporate network. If any party to the file is among the request’s enhanced due diligence parties, enhanced due diligence must be completed.

Disbursement authorization

A user with the senior escrow officer or escrow manager role may authorize a disbursement only when the user’s authority level and the associated escrow file’s disbursement tier are each one of 0, 1, 2, or 3. The disbursement amount and the file’s held amount must each be at least $0.00, and the held amount must be at least the disbursement amount. The associated file must have cleared_to_close status and a file code beginning with the exact text “SETTLEMENT-”, followed by zero or more characters.
