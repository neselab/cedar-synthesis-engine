Equipment Calibration Access

A user may approve an asset’s return to service if and only if the user holds the quality inspector or metrology manager role, the asset’s status is calibrated, and the request is made on the plant network. If the asset’s hazard class includes biological, hazard signoff must also have been recorded.

A user may calibrate an asset if and only if the user holds the calibration technician or senior technician role, the user’s certification level and the asset’s equipment class are each one of 0, 1, 2, or 3, the asset’s measurement point count is nonnegative, the asset’s status is due, the clean room has been certified, and the request is made on the plant network.

These are the only permissions, and they depend on the current recorded facts without changing asset state or requiring an execution order between the activities.
