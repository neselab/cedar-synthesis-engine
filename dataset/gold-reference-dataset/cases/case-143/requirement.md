Payout Disbursement Access

A user may disburse a payout only if they hold the payout agent role, have used multi-factor authentication, and the payout’s account has a KYC tier of 0, 1, 2, or 3. The payout amount must be at least $0.00, and an approver must be recorded on the payout; if no approver is recorded, disbursement is not permitted. Amounts in the supplied records are stored in whole US cents.

The user must be the payout’s initiator unless an emergency has been declared and the user holds the payout agent role. This exception waives only the requirement to be the initiator; all other requirements still apply.

If the payout amount exceeds $25,000.00, the host application must confirm completion of the additional review. These are the only permissions: disbursement is permitted when all applicable requirements above are met, and no other activity is authorized by this requirement.
