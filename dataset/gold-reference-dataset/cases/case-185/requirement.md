Inpatient Prescription Access

A user may countersign a prescription only if the user holds the Attending Physician role, is the prescription’s recorded prescriber, the prescription is in draft status, and the user has used multi-factor authentication.

A user may dispense a prescription only if the user holds the pharmacist role, the prescription is in countersigned status, and the user has used multi-factor authentication.

A user may write a prescription only if the user holds the Attending Physician role and is not the prescription’s patient.

These are the only permissions: each activity is permitted when all its stated conditions are met, and all other requests are denied. Users may hold multiple roles; role membership does not establish that a user is the recorded prescriber. Decisions use current recorded facts and do not change record states or establish an order for these activities.
