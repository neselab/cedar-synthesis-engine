Lease Execution and Review Access

A user with the broker role, the compliance officer role, or both may execute a lease through an executed-lease record only when its linked lease has monthly rent of at least $0.00, has signed status, and includes “regulated” among its segments.

A user with the broker role, the transaction coordinator role, or both may review a lease only when it has monthly rent of at least $0.00, nonnegative square footage, a term of 1 through 120 months inclusive, and drafted status. The lease code must begin with the exact, case-sensitive prefix “COMMERCIAL-”, followed by zero or more characters. If monthly rent exceeds $10,000.00, the reviewing user must have the broker role; at exactly $10,000.00, this additional requirement does not apply.

Amounts in the supplied records are stored in whole US cents. These are the only permissions, and all stated requirements for the requested activity must be met using current recorded facts. These permissions do not change records or establish an order between execution and review.
