Claim Approval and Payout Authorization

A user may approve a claim only if the user holds the reviewer or claims manager role, the claim amount and deductible are each at least $0.00, the line item count is at least zero, and the claim code begins with “AUTO-” followed by any sequence of characters, including none. The user must not be the claim’s handler unless a catastrophe has been declared and the user holds the claims manager role. This exception waives only the handler restriction; all other approval requirements still apply.

A user may issue a payout only if the user holds the payout officer or claims manager role, the payout amount and its claim’s amount and deductible are each at least $0.00, and the claim’s line item count is at least zero. The claim must have approved status and a code beginning with “LIABILITY-” followed by any sequence of characters, including none. The payout amount must equal the claim amount minus the deductible.

Amounts in the supplied records are stored in whole US cents. These are the only permissions, and each is sufficient only when all its stated requirements hold under the current recorded facts. These permissions do not change records or require an execution order between claim approval and payout issuance.
