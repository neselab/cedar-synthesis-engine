Document Viewing Access

A user may view a document if and only if the user holds the attorney role, is the document’s author, and does not have the document’s matter recorded among their conflicted matters. Paralegal or records manager membership alone is not sufficient. A sealed document must also be marked as filed; this filing requirement does not apply to documents that are not sealed.

If the document is privileged, the trusted application context must also authorize privileged access. This additional requirement applies only to privileged documents; all other requirements remain in force regardless of privilege status. These are the only permissions, and no other activities are authorized by this requirement.
