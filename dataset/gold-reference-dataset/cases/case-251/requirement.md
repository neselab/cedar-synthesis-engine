Shipment Delivery Confirmation

A user with the driver or depot supervisor role may confirm delivery of a shipment only when its status is intransit, its piece count is at least 0, and the request is on the depot network.

If the shipment’s hazmat class contains “corrosive,” a custody signature must have been captured. If the shipment’s piece count exceeds 1,000, the host application must confirm that the additional review is complete. Each conditional requirement applies only when its stated condition is met; all other requirements continue to apply.

These are the only permissions granted, and no other actions are permitted under this requirement.
