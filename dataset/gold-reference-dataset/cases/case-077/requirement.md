Equipment Calibration Access

A user may approve an asset’s return to service only if the user holds the quality inspector or metrology manager role, is not the asset’s recorded technician, and the clean room has been certified. If the asset’s hazard class includes radiological, hazard signoff must also have been recorded.

A user may calibrate an asset only if the user holds the calibration technician or senior technician role and has a certification level of 0, 1, 2, or 3. The asset must have an equipment class of 0, 1, 2, or 3, a nonnegative measurement point count, a status of due, and be recorded as out of service. Its calibration due time must be at or before the request’s current time, with times interpreted in UTC.

These are the only permissions: each activity is permitted exactly when all its stated requirements are met, and no other activities are authorized. Users may hold multiple roles. Permissions are determined from current recorded facts and do not change records or require an order between these activities.
