Escrow Approval and Disbursement Authorization

A user may approve an escrow file as clear to close only if the user holds the title officer or escrow manager role, the file’s held amount is at least $0.00, and its payee count is at least zero. If the held amount exceeds $50,000.00, the approving user must differ from the file’s escrow officer. If the payee count exceeds 10, the approving user must hold the escrow manager role.

A user may authorize a disbursement only if the user holds the senior escrow officer or escrow manager role. The user’s authority level and the associated escrow file’s disbursement tier must each be one of 0, 1, 2, or 3. The disbursement amount and the file’s held amount must each be at least $0.00, and the file’s title must be recorded as cleared.

For disbursement authorization, the user’s authority level must be at least the associated file’s disbursement tier unless an emergency has been declared in the trusted application context and the user holds the senior escrow officer or escrow manager role. This exception waives only the authority-level comparison; all other requirements, including the permitted authority levels and tiers, still apply.

Amounts in the supplied records are stored in whole US cents. These are the only permissions: each activity is permitted if and only if all its applicable requirements above are met. These permissions neither change records nor require an order between the two activities.
