Marketplace Payout Authorization

These are the only permissions: a user may approve or disburse a payout only under the applicable requirements below. Both activities require the payout’s account to have a KYC tier of 0, 1, 2, or 3 and the payout amount to be at least $0.00. Amounts in the supplied records are stored in whole US cents. These permissions neither change records nor require either activity to precede the other.

A user with the finance approver role may approve a payout. If the amount exceeds $500.00, the user must be different from the payout’s initiator unless an emergency has been declared and the user has the finance approver role. This exception waives only the requirement to be different from the initiator; all other approval requirements still apply.

A user with the payout agent role may disburse a payout only if that user is the payout’s initiator and the payout’s account has a fraud status of clear. If the amount exceeds $5,000.00, the host application must also confirm completion of the additional review.
