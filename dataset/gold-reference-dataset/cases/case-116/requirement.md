Document Editing Access

A user may edit a document only if they hold the author role, the editor role, or both, and are the document’s recorded owner. The user’s clearance and the document’s classification must each be one of 0, 1, 2, or 3, and the user’s clearance must be at least the document’s classification. The document must carry the “external” label, and the request must be made on the corporate network.

These are the only permissions: document editing is permitted when all of these requirements are met, and no other actions are permitted.
