Inpatient Prescription Access

A user may countersign a prescription only if the user holds the Attending Physician role, is the prescription’s recorded prescriber, and has used multi-factor authentication.

A user may dispense a prescription only if the user holds the pharmacist role, the prescription’s recorded status is countersigned, and the user has used multi-factor authentication.

A user may write a prescription only if the user holds the Attending Physician role, is not the prescription’s patient, and has used multi-factor authentication.

These are the only permissions, and each activity is permitted whenever all its stated requirements are met. Users may hold multiple roles; role membership does not establish that a user is the recorded prescriber or patient. These permissions neither change records nor require an order of execution.
