Repository Cloning Access

A user may clone a repository only if the user holds at least one of the developer, reviewer, maintainer, or security lead roles. The user’s clearance and the repository’s sensitivity must each be 0, 1, 2, or 3, and the user’s clearance must be at least the repository’s sensitivity.

The repository must have incubating status and include “security” among its topics, and the request must use the VPN. These conditions together define the only permission granted by this requirement; no other actions are permitted.
