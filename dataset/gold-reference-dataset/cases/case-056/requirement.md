Repository Cloning Access

A user may clone a repository only if the user holds at least one of the developer, reviewer, maintainer, or security lead roles, owns the repository, and is a member of its team. The repository must be active and include “infrastructure” among its topics. The user’s clearance and the repository’s sensitivity must each be one of 0, 1, 2, or 3, and the user’s clearance must be at least the repository’s sensitivity.

These are the only permissions: cloning is allowed when all of these requirements are met, and no other operations are authorized by this requirement.
