Patent Application Access

A user may access a patent application only if the user holds the docket clerk role and is a member of the application's team. The user must hold at least one of the patent attorney, docket clerk, or examiner roles; the mandatory docket clerk role satisfies this requirement. The user's clearance and the application's confidentiality must each be 0, 1, or 2.

The user's clearance must be at least the application's confidentiality unless the request's court order flag is true and the user holds at least one of those three roles. This exception waives only the clearance comparison; all other requirements remain in force.

These are the only permissions: access is allowed only when all applicable requirements above are met, and no other action is permitted.
