Access to Patent Applications

A user may access a patent application only if the user holds the docket clerk role, belongs to the application's team, and the application is under examination. Both the user's clearance and the application's confidentiality must be one of the levels 0, 1, or 2.

The user's clearance must be at least the application's confidentiality unless the request is marked as having a court order. This exception waives only the clearance comparison; the permitted levels, docket clerk role, team membership, and application status requirements still apply. Holding the patent attorney or examiner role without the docket clerk role does not permit access.

These are the only permissions granted; no other actions are permitted.
