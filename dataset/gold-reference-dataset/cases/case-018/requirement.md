Grade Entry and Release Access

A user may enter a grade on a grade entry only if the user holds the teaching assistant role, is not the learner named on that grade entry, and makes the request on the institution network. Holding the instructor of record role alone does not permit grade entry.

A user may release a grade on a grade entry only if the user holds the instructor of record role, is the posting author recorded on that grade entry, and makes the request on the institution network.

These are the only permissions, and each is sufficient when all its stated conditions hold. They do not change records or require either activity to occur before the other.
