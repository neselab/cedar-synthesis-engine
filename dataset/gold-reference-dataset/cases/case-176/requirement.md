Expense Approval and Reimbursement Disbursement

A user may approve an expense report only if they hold the line manager or finance reviewer role, their approval tier and the report’s amount tier are each 0, 1, or 2, and their approval tier is at least the report’s amount tier. The report’s lodging total, meal total, and total amount must each be at least $0.00. The user must not be the report’s submitter unless the request is marked for emergency approval and the user holds the finance reviewer role. This exception waives only the restriction on approving one’s own report; all other approval requirements still apply.

A user may disburse a reimbursement only if they hold the controller role, the reimbursement amount is at least $0.00, and the associated expense report has a recorded approver. Without a recorded approver, disbursement is not permitted. If the reimbursement amount exceeds $5,000.00, the user must also differ from that approver; this separation requirement does not apply at exactly $5,000.00 or below.

Amounts in the supplied records are stored in whole US cents. These are the only permissions, and each activity is permitted if and only if all its stated requirements are met using current recorded facts. These permissions neither change records nor require an execution order between the activities.
