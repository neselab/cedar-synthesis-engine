Inpatient Prescription Access

A user may countersign a prescription only if the user holds the attending physician role, is the prescription’s recorded prescriber, and has used multi-factor authentication, and the prescription is in draft status.

A user may dispense a prescription only if the user holds the pharmacist role and has used multi-factor authentication, and the prescription is in countersigned status.

A user may write a prescription only if the user holds the attending physician role, is not the prescription’s patient, and has used multi-factor authentication.

These are the only permissions: each activity is permitted when all its stated requirements are met, and no other activity is permitted. Decisions use current recorded facts; these permissions neither change record state nor prescribe an order of activities. Users may hold multiple roles.
