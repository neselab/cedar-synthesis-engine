Escrow Clear-to-Close Approval

A user may approve an escrow file as clear to close only if the user holds the title officer or escrow manager role and the file’s region is the same group as, or a descendant of, the user’s assigned group.

The file must have funded status, a held amount of at least $0.00, a payee count of at least zero, and cleared title. Its lien status must not contain “tax_lien”. The request’s current time must be on or before the file’s closing date, with times evaluated in UTC. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: approval is permitted if and only if all of these requirements are met, and no other activity is authorized by this requirement.
