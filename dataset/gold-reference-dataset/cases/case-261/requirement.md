Contract Lifecycle Access

These are the only permissions for users to execute, review, or sign contract records; each permission requires all conditions stated for that activity. Users may hold multiple roles. These permissions neither change contract records nor establish an order for the activities. Amounts in the supplied records are stored in whole US cents. For all three activities, the contract value must be at least $0.00.

Execute a contract: A user with the contract administrator role may execute a contract only when its status is signed. If the contract value exceeds $100,000.00, the host application must also confirm completion of the additional review.

Review a contract: A user with the reviewer role may review a contract. If the contract value exceeds $10,000.00, the user must not be the contract’s drafter.

Sign a contract: A user with the signatory role or the contract administrator role may sign a contract only when its status is approved. The user’s signing authority and the contract’s required authority must each be one of levels 0, 1, or 2. If the contract value exceeds $100,000.00, the user’s signing authority must also be at least the contract’s required authority.
