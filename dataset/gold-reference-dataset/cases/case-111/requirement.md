Number Port Completion

A user may complete a number port only if they hold the line technician or porting supervisor role, the port request has authorized status, its port types include wholesale, and its number block size is at least 0. The request must have regulator escalation flagged as true and must be on the carrier network.

If the number block size exceeds 100, the user must hold the porting supervisor role; holding only the line technician role is not sufficient. These are the only permissions granted, and all applicable requirements must be met.
