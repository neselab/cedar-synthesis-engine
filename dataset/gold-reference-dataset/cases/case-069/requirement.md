Commissioning Request Approval

A user may approve a commissioning request only if they hold the facility manager role, are not the user who requested it, and the request has requested status. The user's membership group must be the same as, or a descendant of, the zone group of the device named in the request.

Approval also requires that the request be made on the site network and that the current time be at or after the scheduled approval start time and strictly before the scheduled approval end time. Times are in UTC.

These are the only permissions granted; no other actions are permitted under this requirement.
