Payroll Run Approval

A user may approve a payroll run only if the user holds the manager role, the run has submitted status, and its amount is at least $0.00. Holding the payroll administrator role without the manager role is not sufficient. Amounts in the supplied records are stored in whole US cents.

The request must use the VPN, and its current time must be at or after its scheduled start time and strictly before its scheduled end time. All times are UTC.

These are the only permissions: approval is allowed when all these requirements are met; otherwise it is denied, and no other actions are permitted.
