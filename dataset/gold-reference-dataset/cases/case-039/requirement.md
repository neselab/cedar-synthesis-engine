Student Record Viewing

A user may view a student record only if the user holds the instructor role, the student’s recorded age is between 0 and 130 inclusive, and the request is made on the campus network. Student, parent, or registrar membership alone does not permit viewing.

The record must not have withdrawn status unless the user also holds the registrar role. This exception waives only the restriction on withdrawn records; all other requirements still apply. If the student is under 18, minor record access must also be authorized.

These are the only permissions to view student records; no other actions are permitted under this requirement.
