Folio Adjustment Posting

A user may post an adjustment to a folio only if the user holds the Front Desk Agent or Night auditor role and has an adjustment authority level of 0, 1, 2, or 3. The folio’s guest segment must also be 0, 1, 2, or 3, and both its adjustment amount and original charge must be at least $0.00. Amounts in the supplied records are stored in whole US cents.

When the adjustment amount exceeds $25.00, the user’s adjustment authority level must be at least the folio’s guest segment. When the folio is flagged as VIP, the request must confirm that VIP handling has been reviewed. The folio’s charges must include “DISPUTED-001”, and the request must be made on the property network.

These are the only permissions: posting a folio adjustment is permitted if and only if all applicable requirements above are met, and no other activity is authorized.
