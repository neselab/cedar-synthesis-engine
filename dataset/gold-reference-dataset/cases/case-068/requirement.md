Enabling External Sharing of Pages

A user with the space administrator role may enable external sharing of a page only when the page is published, its classification is 0 or 1, external sharing is not already enabled, and the request is made on the corporate network. The request’s current time must be at or after its scheduled start time and strictly before its scheduled end time, with all times interpreted in UTC.

These are the only permissions: enabling external sharing is allowed exactly when all these requirements hold, and no other actions are permitted under this requirement.
