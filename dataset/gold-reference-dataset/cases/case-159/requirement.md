Actuator Setpoint Adjustment

A user may adjust an actuator’s setpoint only if the user owns that actuator, holds at least one of the zone controller, maintenance tech, or facility manager roles, and the request indicates that occupancy is detected.

The actuator must be online unless the request’s maintenance override is enabled, the user holds the maintenance tech role, and the actuator is in maintenance status. This exception waives only the online-status requirement; ownership, role membership, and detected occupancy remain required.

These are the only permissions; no other actions are permitted under this requirement.
