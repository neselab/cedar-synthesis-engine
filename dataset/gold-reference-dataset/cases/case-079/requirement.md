Folio Adjustment Permissions

These are the only permissions: a user may approve or post an adjustment to a folio only when all requirements for that activity below are met. Decisions use current recorded facts and trusted information supplied by the host application; these permissions neither change records nor require an order between approval and posting. Amounts in the supplied records are stored in whole US cents.

Approval

A user with the accounting clerk or revenue manager role may approve a folio adjustment when both the adjustment amount and folio balance are at least $0.00 and the folio’s dispute categories include “comp”. If the folio balance minus the adjustment amount exceeds $100.00, the approving user must differ from the folio’s posting author.

Posting

A user with the front desk agent or night auditor role may post a folio adjustment when the user’s adjustment authority level and the folio’s guest segment are each one of 0, 1, 2, or 3; the adjustment amount and original charge are each at least $0.00; the folio is open; and the host application confirms that the dispute has been verified. The user’s assigned code pattern must be exactly “PROPERTY-B-*”, and the folio code must begin with “PROPERTY-B-”, followed by zero or more characters.
