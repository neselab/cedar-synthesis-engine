Immigration Case Adjudication

A user may adjudicate an immigration case only if they hold the adjudication officer or supervisory officer role, the case has checkCleared status, the user is not the case’s applicant, and the request is made on the government network.

The case must not be among the user’s recused cases unless the request includes supervisor approval and the user holds either qualifying role. This exception waives only the recusal restriction; all other requirements still apply. These are the only permissions, and all other requests must be denied.
