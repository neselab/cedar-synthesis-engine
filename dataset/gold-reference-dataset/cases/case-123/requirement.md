Contract Signing Authorization

A user may sign a contract only if the user holds the signatory role, the contract is approved, the contract value is at least $0.00, and both the user’s signing authority and the contract’s required authority are one of the levels 0, 1, or 2. Holding the contract administrator role alone is not sufficient. Amounts in the supplied records are stored in whole US cents.

For contracts valued above $100,000.00, the user’s signing authority must be at least the contract’s required authority unless escalation has been approved and the user holds the signatory role. This exception waives only the authority comparison; all other requirements remain in force. At exactly $100,000.00 or below, no authority comparison is required.

These are the only permissions granted: signing is permitted if and only if these requirements are met, and no other activity is authorized by this requirement.
