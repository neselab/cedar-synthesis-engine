Claim Approval Access

A user may approve a claim only if the user holds the reviewer or claims manager role, is not the claim’s handler, and makes the request on the corporate network. The claim must have reviewed status, must not have its fraud hold flag set to true, and must have a claim code beginning with “PROPERTY-”, followed by any sequence of characters, including none.

The claim amount and deductible must each be at least $0.00, and the line item count must be nonnegative. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: claim approval is permitted if and only if all these requirements are met; no other action is permitted under this requirement.
