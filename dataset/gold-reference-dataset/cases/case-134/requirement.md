Number Port Authorization

A user may authorize a number port request when the user holds the porting specialist or porting supervisor role and all requirements below are met. The request must have a number block size of at least 0, include “wholesale” among its port types, and have a carrier code beginning with “INTERCARRIER-”, followed by any sequence of characters, including none.

The user must be different from the request’s initiator unless the host has declared a port freeze override and the user holds the porting supervisor role. This exception waives only the requirement to be different from the initiator; all other requirements still apply. If the number block size exceeds 100, the host must confirm completion of the additional review.

These are the only permissions: authorization is permitted exactly when these requirements are met, and no other activities are permitted under this requirement.
