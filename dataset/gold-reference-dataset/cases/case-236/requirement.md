Escrow Clear-to-Close Approval

A user may approve an escrow file as clear to close only if the user holds the title officer or escrow manager role, the file’s held amount is at least $0.00, its payee count is nonnegative, its title is recorded as cleared, and its lien status does not include “outstanding_lien.” Amounts in the supplied records are stored in whole US cents.

If the held amount exceeds $1,000,000.00, the approving user must not be the file’s escrow officer. If the payee count exceeds 5, the approving user must hold the escrow manager role. Each additional requirement applies only when its stated threshold is exceeded; all other requirements continue to apply.

These are the only permissions: approval is permitted when all applicable requirements above are met, and no other actions are permitted under this requirement.
