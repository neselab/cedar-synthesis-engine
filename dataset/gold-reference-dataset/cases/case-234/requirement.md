Viewing Recruiting Applications

A user may view a job application only if they hold the recruiter role, the application has received status, its requisition code begins with “FIN-”, and the request is made on the corporate network. Both the user’s personal-information clearance and the application’s personal-information sensitivity must be levels 0, 1, or 2, and the user’s clearance must be at least the application’s sensitivity.

These are the only permissions: viewing is allowed when all these requirements are met, and no other actions are authorized.
