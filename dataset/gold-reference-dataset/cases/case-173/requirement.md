Authorization of Complimentary Benefits

A user with the Shift Manager role, the Front Office Manager role, or both may authorize a complimentary benefit only when the authorization is in requested status and the user is not its requester. The authorization must have a comp value of at least $0.00, an item count of at least zero, and a blackout flag set to false. Amounts in the supplied records are stored in whole US cents.

The current time must be at or after the request’s scheduled authorization start time and strictly before its scheduled authorization end time. All times are UTC.

These are the only permissions: authorization is allowed if and only if all the requirements above are met, and no other actions are permitted under this requirement.
