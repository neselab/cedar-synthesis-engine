Job Offer Approval

A user may approve a job offer only if the user holds the hiring manager role, the offer is in drafted status, and both its compensation and signing bonus are at least $0.00. Amounts in the supplied records are stored in whole US cents.

The approving user must differ from the offer’s extension author unless the request’s executive approval flag is true and the user holds the hiring manager role. This exception waives only the requirement to differ from the extension author; all other requirements still apply.

These are the only permissions: approval is permitted when all applicable requirements above are met, and no other actions are permitted under this requirement.
