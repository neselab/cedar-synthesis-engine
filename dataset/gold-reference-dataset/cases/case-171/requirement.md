Pharmacy Prescription Permissions

These are the only permissions: a user may authorize a refill or verify a prescription only under the corresponding conditions below, using current recorded facts and trusted information supplied by the host application. These permissions neither change records nor require either activity to occur before the other.

Authorize a prescription refill

A user with the pharmacist in charge role may authorize a refill only when the prescription has 0 through 12 refills remaining, inclusive, its status is dispensed, the prescription drug monitoring program (PDMP) has been checked, and the prescriber’s DEA identifier begins with “AB” (including “AB” alone).

Verify a prescription

A user with the staff pharmacist or pharmacist in charge role may verify a prescription only when it has 0 through 12 refills remaining, inclusive, the user is not its entry author, and the PDMP has been checked. When more than 0 refills remain, the host application must also confirm completion of the additional prescription-verification review. That additional review confirmation is not required when 0 refills remain; all other verification requirements still apply.
