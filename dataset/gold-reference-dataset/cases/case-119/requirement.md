Viewing student Records

A user may view a student record only if they hold at least one of the instructor, student, parent, or registrar roles and are themselves the student named in the record. The student's recorded age must be between 0 and 130, inclusive. A withdrawn record may be viewed only by a registrar; this exception does not waive the requirement to be the student named in the record or any other requirement.

The request's current date and time must be at or after its scheduled viewing start and strictly before its scheduled viewing end, using UTC. Access is denied when both the record's FERPA block is active and the request is for directory disclosure.

These are the only permissions: viewing is allowed only when all applicable requirements above are met, and no other actions are permitted.
