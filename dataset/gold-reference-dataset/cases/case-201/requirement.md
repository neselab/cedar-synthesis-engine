Wire Transfer Beneficiary Screening

A user may screen a wire transfer beneficiary only if the user holds the compliance reviewer or treasury officer role, is the transfer’s recorded screener, and the transfer has drafted status. The request’s current time must be strictly earlier than its daily cutoff; both times are in UTC.

If the transfer’s currency code is exactly EUR, the currency review must also be complete. This review requirement does not apply to other currency codes; all other requirements still apply.

These are the only permissions granted by this requirement.
