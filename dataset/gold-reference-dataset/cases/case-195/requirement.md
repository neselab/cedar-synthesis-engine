Viewing Applicant Records

A user may view an applicant record only if the user holds the supervisory officer role, belongs to the record’s need-to-know team, and makes the request on the government network. The record must be active. The user’s clearance and the record’s data sensitivity must each be 0, 1, or 2, and the user’s clearance must be at least the record’s data sensitivity.

These are the only permissions: access is allowed when all these requirements are met, and no other activity is authorized.
