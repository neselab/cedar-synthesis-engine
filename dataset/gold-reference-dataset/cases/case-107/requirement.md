Lease Review Access

A user may review a lease only if the user holds the broker role, the transaction coordinator role, or both, has a verified identity, and makes the request on the brokerage network.

The lease must be in drafted status, have monthly rent of at least $0.00, have nonnegative square footage, and have a term of 1 through 120 months, inclusive. Its lease code must start with “CONTROLLED-”, followed by any sequence of characters, including none. The request’s current time must be strictly earlier than the lease’s sign window end, with times interpreted in UTC. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: lease review is permitted if and only if all these requirements are met, and no other action is permitted.
