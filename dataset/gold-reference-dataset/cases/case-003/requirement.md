Inpatient Prescription Permissions

A user may countersign a prescription only if the user holds the Attending Physician role, is the prescription’s recorded prescriber, has used multi-factor authentication, and the prescription is in draft status.

A user may dispense a prescription only if the user holds the pharmacist role and the prescription is in countersigned status.

A user may write a prescription only if the user holds the Attending Physician role, is not the prescription’s patient, and has used multi-factor authentication.

These are the only permissions: each activity is permitted whenever all its stated conditions hold, based on the current recorded facts. These permissions do not change records or establish an execution order.
