Payroll Run Approval

A user with the manager role, the payroll administrator role, or both may approve a payroll run only when its status is submitted, its amount is at least $0.00, and the request is made using the VPN.

If the payroll run’s amount exceeds $500,000.00, the approving user must be different from the user who prepared it. This separation requirement does not apply at or below $500,000.00; all other requirements still apply. Amounts in the supplied records are stored in whole US cents.

These are the only permissions: approval is allowed when all applicable requirements above are met, and no other actions are permitted under this requirement.
