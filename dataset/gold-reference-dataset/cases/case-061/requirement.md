Patent Response Filing

A user may file a patent response only if the user holds the patent attorney role, is the application's recorded prosecuting attorney, and belongs to the application's team. The filing must be in draft status, the request's current date must be strictly earlier than the application's bar date, and the user must have used multi-factor authentication. Dates and times are evaluated in UTC.

These are the only permissions granted; no other actions are permitted under this requirement.
