Clearing Security Checks

A user may clear a security check if and only if the user holds the background investigator role, is the check’s recorded investigator, and the check has pending status. Holding the supervisory officer role alone is not sufficient.

The request must be made on the government network, at or after its scheduled start time and strictly before its scheduled end time, using the request’s current time. All times are UTC. These are the only permissions; no other actions are authorized by this requirement.
