Page Viewing Access

A user may view a page only if they hold at least one of the reader, contributor, reviewer, or space administrator roles, are the page’s author, and are included in the membership of the page’s space. The page must have the label “external”. Both the user’s clearance and the page’s classification must be one of 0, 1, 2, or 3.

The user’s clearance must be at least the page’s classification unless emergency access is enabled for the request and the user holds the space administrator role. This exception waives only the clearance comparison; all other requirements still apply.

These are the only permissions: page viewing is allowed when all applicable requirements above are met, and no other action is permitted.
