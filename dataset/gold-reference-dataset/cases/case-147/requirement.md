Payout Issuance

A user may issue a payout only if they hold the payout officer or claims manager role and the request is made on the corporate network. The payout amount, the associated claim amount, and the claim deductible must each be at least $0.00, and the claim must have a nonnegative line item count and no fraud hold. Amounts in the supplied records are stored in whole US cents.

When the claim has more than 100 line items, the user must not be the claim’s approver unless a catastrophe has been declared and the user holds the claims manager role. This exception waives only the requirement to differ from the claim’s approver; all other requirements still apply.

These are the only permissions: a user may issue a payout if and only if all applicable requirements above are met, and no other action is permitted under this requirement.
